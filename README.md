# Portfolio

Personal portfolio built with Next.js 16 App Router.

## Project structure

- `app/` — routes, layouts, and global styles
- `components/common/` — reusable UI components and form fields
- `components/dashboard/` — dashboard sidebar and management forms
- `components/projects/` — project-specific components
- `components/sections/` — public portfolio page sections
- `lib/` — API clients and shared application helpers
- `providers/` — authentication context
- `types/` — shared TypeScript types and configuration
- `public/` — static assets

## Development

```bash
npm run dev
npm run lint
npm run build
```
